# 📊 Introdução à Análise de Dados com NotebookLM

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio da DIO, com o objetivo de explorar o uso da Inteligência Artificial como ferramenta de aprendizagem ativa.

Para isso, utilizei o **NotebookLM** como apoio no estudo dos fundamentos da análise de dados, utilizando fontes selecionadas previamente para orientar as respostas da IA e organizar os conhecimentos adquiridos.

O projeto também documenta a utilização de diferentes prompts, os resultados obtidos e as limitações encontradas durante o processo.

---

## 🎯 Contexto e objetivos

A análise de dados está cada vez mais presente nas organizações e é utilizada para transformar dados em informações que apoiam a tomada de decisões.

O objetivo deste caderno temático foi construir uma compreensão inicial sobre:

* O conceito de análise de dados;
* A importância da organização e limpeza dos dados;
* A identificação de padrões, tendências e anomalias;
* O uso de ferramentas como Excel e Power BI;
* A utilização de visualizações para comunicação de informações;
* A aplicação da análise de dados em situações reais de negócios.

Além do aprendizado do conteúdo, o projeto teve como objetivo desenvolver uma forma mais crítica de utilizar ferramentas de Inteligência Artificial, verificando as fontes utilizadas e identificando limitações nas respostas.

---

## 🧠 Metodologia

O estudo foi realizado utilizando o **NotebookLM**, ferramenta utilizada para consultar e analisar as fontes selecionadas.

O processo foi dividido em três etapas:

1. Seleção de fontes confiáveis;
2. Elaboração e teste de prompts;
3. Análise das respostas e consolidação dos conhecimentos em um miniguia.

Os prompts foram progressivamente elaborados para sair de perguntas conceituais e chegar a uma situação prática de análise de dados.

# 🤖 Engenharia de Prompts

Durante o projeto, foram realizados três testes principais.

## Prompt 1 — Compreensão do conceito

> Com base exclusivamente nas três fontes adicionadas, explique o que é análise de dados. Considere que o leitor é iniciante e nunca estudou o assunto. Apresente uma definição simples, os principais objetivos da análise de dados e um exemplo prático. Ao final, indique quais fontes sustentam cada informação apresentada.

### Resultado

O NotebookLM apresentou a análise de dados como um processo de organização, limpeza, transformação e exame de dados para transformar informações brutas em insights.

A resposta também apresentou objetivos como:

* obtenção de insights;
* apoio à tomada de decisões;
* identificação de padrões e anomalias;
* resumo de informações;
* comunicação dos resultados por meio de recursos visuais.

Foram apresentados exemplos envolvendo manutenção preditiva, Excel e Power BI.

### Aprendizado

O primeiro prompt foi útil para construir uma visão geral do assunto e estabelecer uma base conceitual para os próximos questionamentos.

---

## Prompt 2 — Comparação de conceitos

> Com base nas fontes fornecidas, explique a diferença entre análise descritiva, diagnóstica, preditiva e prescritiva. Organize a resposta em uma tabela com as colunas: tipo de análise, pergunta principal, objetivo e exemplo prático. Não utilize informações que não possam ser relacionadas às fontes.

### Resultado

Neste teste ocorreu uma limitação importante.

O NotebookLM informou que as fontes selecionadas **não apresentavam nem definiam formalmente a classificação em análise descritiva, diagnóstica, preditiva e prescritiva**.

Por isso, a ferramenta não forneceu a tabela solicitada utilizando apenas as fontes disponíveis.

### 🩹 Cicatriz / Troubleshooting

Esse resultado mostrou a importância de não considerar automaticamente uma resposta da IA como correta ou completa.

Em vez de simplesmente aceitar uma resposta baseada em conhecimento externo, o prompt determinava que a resposta deveria utilizar exclusivamente as fontes fornecidas.

A própria ferramenta identificou que não possuía informações suficientes para responder à pergunta dentro dessa restrição.

### Aprendizado

Uma das principais conclusões desse teste foi que **a qualidade da resposta depende também da qualidade e abrangência das fontes utilizadas**.

Um prompt bem elaborado não substitui uma curadoria adequada das fontes.

# 📖 Miniguia de Estudo

## 1. O que é análise de dados?

A análise de dados consiste em organizar, limpar, transformar e examinar dados para encontrar informações úteis, padrões, tendências e possíveis anomalias.

Seu objetivo não é apenas produzir números, mas transformar dados em informações que possam ajudar na compreensão de uma situação e na tomada de decisões.

---

## 2. Etapas básicas

Uma análise pode envolver diferentes etapas:

**Dados brutos → Organização → Limpeza → Análise → Visualização → Insights → Decisão**

### Organização

Os dados precisam estar estruturados para que possam ser analisados corretamente.

### Limpeza

Erros, inconsistências e informações inadequadas precisam ser identificados e tratados.

### Análise

Os dados são examinados para identificar padrões, tendências, relações e anomalias.

### Visualização

Gráficos, tabelas e dashboards podem facilitar a interpretação dos resultados.

### Insights

A análise permite transformar os resultados encontrados em informações úteis.

### Tomada de decisão

Os insights podem apoiar decisões baseadas em evidências.

# 📊 Excel e Power BI

## Excel

O Excel pode ser utilizado para organizar, explorar e analisar dados, utilizando recursos como tabelas, gráficos e tabelas dinâmicas.

## Power BI

O Power BI pode ser utilizado para conectar fontes de dados, trabalhar com modelos de dados e criar relatórios e visualizações interativas para facilitar a análise e a comunicação dos resultados.

# 🔎 Exemplo prático

Imagine uma empresa que identificou uma redução de **15% nas vendas**.

Um analista poderia:

1. Verificar se os dados estão completos e atualizados;
2. Organizar e limpar os registros;
3. Comparar as vendas atuais com períodos anteriores;
4. Identificar quais produtos ou regiões apresentaram maior redução;
5. Procurar padrões e anomalias;
6. Investigar possíveis causas;
7. Criar visualizações para apresentar os resultados;
8. Compartilhar os insights com os responsáveis pela tomada de decisão.

O objetivo final seria transformar a queda observada em uma investigação estruturada que permita compreender o problema e apoiar possíveis ações.

# 📚 Glossário

| Termo                           | Significado                                                                         |
| ------------------------------- | ----------------------------------------------------------------------------------- |
| **Análise de dados**            | Processo de examinar dados para obter informações e insights úteis.                 |
| **Dados brutos**                | Dados que ainda não foram tratados ou organizados para análise.                     |
| **Insight**                     | Informação relevante obtida a partir da análise dos dados.                          |
| **Dashboard**                   | Painel visual utilizado para acompanhar informações e indicadores.                  |
| **Anomalia**                    | Comportamento ou valor que se diferencia do padrão esperado.                        |
| **Tendência**                   | Direção ou comportamento observado nos dados ao longo do tempo.                     |
| **Análise exploratória**        | Processo de explorar e resumir dados para identificar padrões e anomalias.          |
| **Business Intelligence (BI)**  | Uso de dados e ferramentas para gerar informações que apoiam decisões empresariais. |
| **DAX**                         | Linguagem utilizada para criar cálculos e medidas no Power BI.                      |
| **Data-driven decision making** | Tomada de decisão orientada por dados.                                              |
| **Tabela dinâmica**             | Recurso utilizado para resumir e analisar dados de forma organizada.                |
| **Modelagem de dados**          | Organização das estruturas e relações entre diferentes conjuntos de dados.          |

# 💡 Principais aprendizados

A realização deste projeto permitiu perceber que utilizar Inteligência Artificial para estudar não significa apenas fazer perguntas e aceitar as respostas.

É necessário:

* selecionar fontes confiáveis;
* formular perguntas claras;
* fornecer contexto;
* estabelecer critérios para as respostas;
* verificar as referências;
* identificar limitações;
* reformular perguntas quando necessário;
* avaliar criticamente o resultado produzido pela IA.

Um dos principais aprendizados foi perceber que **um bom prompt e boas fontes trabalham juntos**. Quando uma informação não está presente nas fontes, mesmo uma pergunta bem estruturada pode não produzir uma resposta adequada.
